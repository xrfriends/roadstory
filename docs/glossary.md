# 용어 사전(Glossary)

| 공식 한글명 | 영문 Domain Name | Code 예시 |
|---|---|---|
| 이야기 | Story | `Story`, `storyId` |
| 장소 | Place | `Place`, `placeId` |
| 재생 조건 | Playback Trigger | `PlaybackTrigger` |
| 주행 세션 | Journey Session | `JourneySession` |
| 목적지 재생 목록 | Destination Playlist | `DestinationPlaylist` |
| 테마 코스 | Theme Course | `ThemeCourse` |
| 검수 상태 | Verification Status | `VerificationStatus` |
| 주행 상태 | Driving State | `DrivingState` |
| 관심 주제 | Content Preference | `UserPreferences` |
| 유료 사용 권한 | Entitlement | `Entitlement` |
| 출처 | Source | `SourceReference` |
| 콘텐츠 신고 | Content Report | `ContentReportRequest` |
| 중복 제한 시간 | Cooldown | `cooldownSeconds` |

## 작성 규칙

- 설명, 정책, 실제 UI 문구는 한글로 작성한다.
- 파일명, Directory, ID, API Path, JSON Field, Class, Enum, Event Name은 영어를 유지한다.
- 동일 개념에 여러 번역어를 사용하지 않는다.
