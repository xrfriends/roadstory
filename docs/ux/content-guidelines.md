# 콘텐츠 작성 가이드(Content Guidelines)

## 목표

이동 중 쉽게 이해할 수 있는 짧고 신뢰도 높은 지역 Story를 작성한다.

## 원칙

1. 기억에 남는 Hook으로 시작한다.
2. 현재 장소와의 관련성을 설명한다.
3. 검증된 사실만 사용한다.
4. 사실, 해석, 전설을 구분한다.
5. 과도한 학술 표현과 관광 홍보 문구를 피한다.
6. 읽기보다 듣기에 자연스럽게 쓴다.
7. 사용자가 장소를 지나기 전에 끝낸다.

## Story 구조

### 30초
Place 소개 → 핵심 사실 1개 → 현재와의 연결

### 60초
Hook → 역사·문화 맥락 → 보조 사실 → 현재와의 연결

### Mobile Long Version
전체 맥락, 날짜, 인명, 논쟁, Source, Image, Timeline, Related Story

## Voice

차분함, 호기심, 신뢰감, 현대적 말투, 일관된 높임말. 유행어와 지나친 감상 표현을 피한다.

## Source 정책

모든 `PUBLISHED` Story에는 Source 기관·저자, 제목, 발행일, URL·Archive Reference, Rights Status, Reviewer, 최근 검수일이 있어야 한다.

## 신뢰도 등급

| 등급 | Source |
|---|---|
| A | 중앙정부·국가기관·공식 Archive |
| B | 지자체·박물관·도서관·문화원 |
| C | 논문·대학 연구·전문 출판 |
| D | 신뢰 언론·전문가 인터뷰·구술 |
| E | 검수 대기 사용자 제보 |

E 등급은 검증 사실로 발행하지 않는다.

## 불확실성 Label

`확인된 사실`, `유력한 해석`, `여러 설 중 하나`, `지역에 전해지는 이야기`

## AI 사용

허용: Source 추출, Draft, 요약, 연령 조정, Pronunciation 후보, Translation Draft  
금지: 자동 Publish, Source 생성, Rights 판단, 역사 논쟁의 자동 결론

## 발행 Checklist

```text
[ ] Source
[ ] Rights
[ ] 날짜·인명
[ ] 사실·전설 구분
[ ] 발음
[ ] 30초·60초 Timing
[ ] Trigger
[ ] 주행 문장
[ ] Reviewer 승인
```
