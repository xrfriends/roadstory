# 사용자 흐름(User Flows)

## FLW-NAV-001 — 차량 앱 메뉴

```text
정차 상태 Home/Player → 로드스토리 ⌄ 또는 앱 아이콘 → SCR-APP-MENU-001
├─ 홈 → SCR-HOME-001
├─ 지금 듣기 → SCR-PLAYER-001
├─ 내 이야기 → SCR-SAVED-001
├─ 설정 → SCR-SETTINGS-001 → 관심 주제/청취 설정 → 차량 로컬 Preference 저장
└─ Back / 바깥 터치 → 메뉴 닫기, 기존 화면 유지
```

차량 앱의 어느 화면에서든 주행 제한이 활성화되면 열린 메뉴를 닫고 `SCR-DRIVE-LIMIT-001`로 전환한다. 규제 상태 확인 전, 차량 서비스 연결 단절, 규제 소스 실패에도 이 화면을 표시한다. 제한 해제 신호가 들어오면 제한 전 화면을 복구한다. 앱이 Background로 이동해도 메뉴를 닫는다. 내 이야기는 이 차량의 저장·코스·청취 기록을 표시하며, 서버 동기화는 로컬 동작과 별도 범위다.

## FLW-ONB-001 — Onboarding

```text
App 실행 → 가치 안내 → 위치 목적 안내 → 관심 주제 → Permission → SCR-HOME-001
```

거부 시 제한 모드와 설정 이동을 제공한다.

## FLW-FREE-001 — 자유 주행

```text
SCR-HOME-001 → 주변 이야기 듣기 → 위치 권한·유효한 위치 확인 → 공개 후보 조회 → SCR-PLAYER-001
```

후보가 없으면 `SCR-EMPTY-001`을 표시한다. 위치 권한이 없거나 현재 위치를 확인하지 못하면 상태와 정차 중 권한 요청·다시 확인 방법을 표시한다.

차량 앱은 주변 공개 후보에서 `끄기` 주제와 `관심 없음`으로 표시한 Story를 제외한다. 가족 우선일 때는 가족 적합 표시가 있는 후보를 앞에 둔다. 그 안에서 관심 없음과 같은 주제는 뒤로 보내고, 나머지는 `자주`, `가끔`, 서버 응답 순서로 결정한다. 후보가 모두 제외되면 주차 중 설정을 확인한 뒤 다시 시작할 수 있다.

## FLW-PLAY-001 — Playback

```text
Story 시작
├─ 완료 → Auto-play가 켜져 있고 다음이 있으면 다음 Story, 아니면 정지 상태
├─ 다음 → 큐의 다음 Story를 바로 재생
├─ 저장 → sync
├─ 관심 없음 → 유사 Story 감소
├─ 자동 재생 종료 → 현재 Story를 끝까지 재생한 뒤 멈춤
└─ 종료 → JourneySession 종료
```

주행 제한 중에는 `SCR-DRIVE-LIMIT-001`에서 재생·일시정지, 다음, 저장, 관심 없음, 종료를 조작할 수 있다. 정차 시에만 허용되는 요청은 실행 직전에 차량 규제를 확인한다. 이 기준은 제한 전 화면의 콜백에도 적용된다. 시스템 미디어 명령에서는 현재 이야기의 재생·일시정지, 다음, 종료를 허용하고, ID를 지정한 이야기 선택·재생은 차단한다.

차량 앱의 `관심 없음`은 화면에 표시된 Story ID와 알 수 있는 주제를 차량에 한 번 기록하고 선택 상태를 표시한다. 동일 Story를 이후 주변 추천에서 제외하고 같은 주제의 우선순위를 낮춘다. 설정이나 관심 없음이 바뀌어도 현재 재생은 유지하고, 이후 후보와 다음 미리보기만 갱신한다.

차량 앱의 `주변 이야기 시작`은 확인한 현재 위치의 공개 후보와 차량 설정을 사용한다. 내 이야기에서 개별 Story를 선택하면 추천에서 제외된 ID도 사용자의 선택대로 재생한다. 동일 ID는 한 세션에서 다시 추천하지 않는다. 설정의 Auto-play가 꺼져 있어도 수동 `다음`은 작동한다. `자동 재생 종료`는 현재 세션에 적용하고 새 세션에서 해제한다. `종료`는 즉시 대기 요청·재생·재개를 취소한다.

## FLW-INTERRUPT-001 — Navigation·Call

```text
Story 문장 재생 → 일시적 Focus 상실 → 문장 체크포인트·들은 시간 유지 → Focus 복귀 → 중단 문장부터 재생
                                  └─ 사용자 일시정지·종료 → 자동 재개 취소
Story 재생 → 화면 꺼짐·Suspend 진입 → 체크포인트 유지·재생 자원 해제 → 사용자 재생 → 중단 문장부터 재생
앱 다시 열기 → 현재 계정 또는 비회원의 일시정지 상태 표시 → 사용자 재생 → 중단 문장부터 재생
```

문장 완료 이벤트가 체크포인트를 진행시킨다. 중단된 문장은 다시 들을 수 있다. `들은 시간`은 실제 `PLAYING` 구간을 누적하고 중단·준비 시간은 제외한다. 사용자 종료와 다른 Story로 전환은 현재 사용자의 이전 체크포인트를 해제한다. 계정별·비회원별 체크포인트는 차량에 보관한다. 다시 재생할 때 낭독문이 변경됐으면 첫 문장부터 듣는다.

파일 음원이 등록된 Story는 온라인에서 한 번 재생하거나 정차 중 `오프라인 저장`을 선택해 차량에 받는다. 연결을 사용할 수 없으면 최근 Story 또는 내 이야기에서 같은 Story를 선택해 내려받은 음원을 재생한다. 일시정지 후 `재생`을 누르면 같은 파일의 저장 위치부터 이어듣는다.

## FLW-DEST-001 — 목적지 Playlist

```text
SCR-HOME-001 → 목적지까지 이야기 → 내비 안내 상태·목적지·남은 시간 확인 → SCR-DEST-001 → 편성 또는 개별 Story 재생
```

차량의 NaviHelper에서 경로 좌표를 제공하지 않는 경우 확인한 목적지 주변 공개 Story를 남은 시간 안에서 편성한다. 화면에 목적지 주변 기준을 표시한다. 서버는 경로 좌표와 출발점이 제공되는 요청에도 응답할 수 있다.

재탐색 또는 목적지 변경 시 현재 Story를 유지하고 이후 후보만 다시 편성한다. 목적지 안내가 종료되거나 편성할 시간이 부족하면 이후 후보를 비운다.

```text
공개 Course 목록 → 선택한 Course 상세 → 코스 이야기 또는 개별 Story 재생
                                  └─ 첫 장소 길 안내 → 정차 확인 → 첫 정차점 내비 요청
```

## FLW-SAVE-001 — 저장 후 Mobile 확인

```text
비회원 Vehicle 저장 → 이 차량의 내 이야기
인증 사용자 Vehicle 저장 → 즉시 표시 → 계정별 서버 저장 → 다른 기기의 같은 계정 목록
정차 중 가져오기 선택 → 선택한 비회원 이야기·코스 복사 → 계정의 저장 목록
```

청취 이력은 재생 시작 시 최신 Story별 기록을 저장한다. 연결이 끊기면 같은 계정의 대기 요청을 유지하고 다시 연결됐을 때 전송한다. 로그아웃이나 계정 전환 시 이전 계정의 데이터와 대기 요청을 다른 계정에 적용하지 않는다.
