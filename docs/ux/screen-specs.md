# 화면 명세(Screen Specifications)

## 공통

- Vehicle은 큰 Touch Target과 높은 Contrast를 사용한다.
- 차량 앱은 주행 제한이 활성화되면 요청된 화면을 `SCR-DRIVE-LIMIT-001`로 표시한다. 제한 해제 신호가 들어오면 제한 전 화면으로 복귀한다.
- 모든 Data Screen은 `loading`, `empty`, `error`, `success`를 가진다.
- 긴 Text와 Image Gallery는 정차 또는 Mobile에서만 제공한다.
- 화면 내부에 `SCR-`, `REQ-`, `FLW-` 같은 관리용 ID를 노출하지 않는다. ID는 DOM의 `data-screen-id`로 연결한다.
- 차량 화면의 주요 Action은 PLEOS Medium 80dp, Mode 선택은 Small 64dp 이상을 기준으로 한다. 강조가 큰 단일 Action은 Large 100dp를 사용할 수 있다.
- 정보 계층은 `현재 Context → 핵심 제목 → Primary Action` 순서로 유지하며 Primary Action은 화면당 하나만 강하게 강조한다.
- PLEOS Dark Neutral Surface, 흰색 Filled Action, 상태용 Green/Blue/Red, 48~60px Headline, 26~30px Body를 공통 Vehicle Design Token으로 사용한다.
- 차량 서비스·미디어 연결을 기다리는 동안에도 초기 화면을 렌더링한다. 규제 정보 확인 전과 생성/조회/관측 실패 시에는 제한 상태를 유지한다.
- 재생/일시정지 또는 저장/해제로 접근성 문구가 바뀌어도 동일 조작이 남아 있으면 DPAD/키보드 Focus를 유지한다.

## SCR-APP-MENU-001 — 차량 앱 메뉴
- 연결: `REQ-USER-001`, `REQ-USER-002`, `REQ-USER-003`, `REQ-STORY-005`; `FLW-NAV-001`, `FLW-SAVE-001`, `FLW-PLAY-001`; `AC-PLAY-002`.
- 정차 중 상단 `로드스토리 ⌄` 또는 앱 아이콘을 누르면 현재 View를 Anchor로 메뉴를 연다. 홈으로 바로 이동하지 않는다.
- 항목: `홈` → `SCR-HOME-001`, `지금 듣기` → `SCR-PLAYER-001`, `내 이야기` → `SCR-SAVED-001`, `설정` → `SCR-SETTINGS-001`.
- 항목은 최소 80dp, 현재 화면을 선택 상태로 표시하며 Rotary/DPAD Focus를 지원한다.
- 메뉴는 둥근 Surface와 테두리를 사용한다. 홈·헤드폰·북마크·설정 Outline 아이콘, 왼쪽 정렬 문구, 현재 항목의 회색 배경과 우측 체크 표시를 시안에 맞춘다. 선택 상태를 초록색 글자만으로 표현하지 않는다.
- 홈·지금 듣기·내 이야기·설정은 동일한 앱 아이콘/이름/현재 섹션/펼침 화살표 Header를 사용한다. 메뉴가 열리면 화살표 방향과 접근성 상태를 갱신한다.
- 선택 후 메뉴를 닫고 이동한다. 바깥 터치·Back으로 취소하면 기존 화면을 유지한다.
- 주행 제한 중에는 메뉴와 설정 버튼을 표시하지 않는다. 열린 메뉴는 제한 활성화, 화면 재생성, Background 전환 시 닫는다.
- `VehicleAppMenuTest`는 항목별 목적지와 주행 제한 중 메뉴 차단을 검사한다. `VehicleAppMenuDeviceTest`는 정차한 AAOS/Pleos Emulator에서 제목 View 클릭, Popup 열기, Back/바깥 Touch 이벤트 취소와 항목별 이동을 검사한다.

## SCR-SAVED-001 — 내 이야기
- `REQ-USER-001`, `REQ-USER-002`, `REQ-USER-005`, `FLW-NAV-001`, `FLW-SAVE-001`, `FLW-PLAY-001`, `AC-USER-001`에 연결한다.
- 제목은 `다시 만나고 싶은 이야기.`를 사용한다. 비회원에게는 `이 차량에서만 보이는 기록입니다.`를 표시한다.
- 탭은 `저장 N`, `코스 N`, `청취 기록 N`으로 구성한다. 현재 비회원 또는 인증 계정에서 보이는 실제 개수와 선택 배경을 표시한다.
- 저장 Story·코스는 저장/해제에 따라 즉시 목록에 반영하고 앱 재시작 후 유지한다. 청취 기록은 실제 음성 재생 시작 시 기록하며 같은 Story는 중복 행 대신 최근 순서로 갱신한다.
- 저장 탭 빈 상태: Outline Bookmark, `좋았던 이야기를 저장해 보세요.`, `지나간 길의 새로운 의미를 발견해 보세요.`, `주변 이야기 듣기` 버튼을 중앙에 배치한다.
- 코스·청취 기록에도 각각의 빈 상태를 제공한다. Story `듣기`는 해당 ID로 재생을 요청하며 코스는 상세 화면으로 이동한다.
- 고정 Mini Player를 유지한다. 주행 제한 중 진입 차단.
- 인증 계정의 저장과 이력은 서버와 동기화하며 대기 또는 연결 실패 상태를 표시한다. 로그아웃 뒤에는 이 차량의 비회원 기록을 표시한다. 비회원 저장 이야기와 코스는 정차 중 직접 선택해서 계정에 복사할 수 있다.

## SCR-SETTINGS-001 — 앱 설정
- 연결: `REQ-USER-003`, `REQ-USER-004`, `REQ-ONB-004`; `FLW-NAV-001`, `FLW-ONB-001`, `FLW-FREE-001`; `AC-PLAY-006`.
- 제목: `어떤 이야기를 들려드릴까요?`, 설명: `개인화 설정은 주차 중에만 변경할 수 있습니다.`
- 확장 창에서는 `관심 주제`와 `청취 설정`을 두 Surface로 나란히, 좁은 창에서는 세로로 배치한다.
- 관심 주제는 지명 유래·역사적 사건·랜드마크·건축·인물·생활사·시장과 상권·산업화·자연과 지형·어린이 이야기·영화와 문화를 제공한다. 4개씩 3페이지에 나누고 `자주/가끔/끄기` Radio 선택을 제공한다.
- 청취 설정은 `이야기 자동 재생`, `가족 · 어린이 우선` Switch와 Music/Audio 주행 안전 안내를 제공한다.
- 변경은 즉시 차량에 저장되고 재시작 후에도 유지된다. 주변 이야기의 시작 후보와 재생 중인 큐의 다음 후보에 반영한다. 서버 추천·목적지 편성·다른 기기와의 동기화는 별도 범위다.
- 상단 설정 버튼과 앱 메뉴의 설정 항목은 같은 화면으로 이동한다. 고정 Mini Player를 유지하며 주행 제한 중 진입 차단.
- Figma의 모의 네트워크/위치 오류 시나리오 제어는 제품 설정 화면에 포함하지 않는다.

## SCR-ONB-001 — 가치 소개
- 문구: `지나가는 동네의 이야기를 자동으로 들려드립니다.`
- Action: `다음`

## SCR-ONB-002 — 위치 사용 설명
- 위치, 방향, 재생 시점 활용 목적
- Action: `위치 권한 계속`

## SCR-ONB-003 — 관심 주제
- 지명, 역사, 건축, 인물, 생활사, 산업화, 자연, 어린이
- Action: `선택 완료`, `나중에`

## SCR-HOME-001 — 차량 홈
- 주변 이야기는 현재 위치를 사용한다. 위치는 사용자가 주변 재생을 요청할 때 조회한다.
- 내비게이션 안내 중이면 확인된 목적지와 남은 시간을 표시한다. 내비 연결 대기, 목적지 없음, 남은 시간 확인 불가는 각각 실제 상태에 맞게 표시한다.
- 테마 드라이브에는 서버의 공개 코스만 표시한다. 각 카드는 해당 Course ID의 상세로 이동한다.
- Card: `주변 이야기 듣기`, `목적지까지 이야기`, `테마 드라이브`, `최근 이어듣기`
- Primary Card 최대 4개
- `주변 이야기 듣기`를 Featured Card로 표시하고 나머지 세 Card는 보조 Action으로 표현

## SCR-FREE-001 — 자유 주행 시작
- 현재 위치 주변의 Story와 청취 설정을 안내한다. 위치 권한과 유효한 위치가 있어야 주변 후보를 조회한다.
- Action: `이야기 시작`, `관심 주제`, `취소`

## SCR-PLAYER-001 — 현재 재생
- `REQ-PLAY-004`, `REQ-PLAY-006`, `REQ-PLAY-007`, `FLW-PLAY-001`, `FLW-INTERRUPT-001`, `AC-PLAY-004`에 연결한다.
- 제한이 해제된 상태의 재생 화면이다. 주행 제한이 활성화되면 `SCR-DRIVE-LIMIT-001`로 전환한다.
- 제목, Place, Category, `들은 시간`을 표시한다. `들은 시간`은 현재 Story에서 음성이 실제 시작된 `PLAYING` 구간의 누적 청취 시간이며 준비·일시정지·Focus 대기 시간은 제외한다.
- 서버의 예상 길이보다 누적 청취 시간이 짧으면 `예상 남은 시간`을 함께 표시한다. 문장 재청취 시간도 `들은 시간`에 포함한다.
- Action: 이전, 재생·일시정지, 다음, 저장, 관심 없음, 종료
- Transcript와 Source 탐색 미제공
- 제목·들은 시간·재생/일시정지를 가장 높은 계층으로 두고 저장·관심 없음·종료는 Secondary Action으로 표현
- `관심 없음`은 현재 재생을 끊지 않고 이후 주변 추천에서 같은 Story를 제외한다. 알려진 주제는 추천 순위에도 반영한다.
- 다음 미리보기에는 현재 큐의 실제 다음 이야기 제목과 제공된 예상 길이를 표시한다. 다음 항목이 없으면 `다음`은 사용할 수 없다. 후보 없음·조회 실패는 별도로 표시하고, 재시도는 같은 시작 요청을 다시 실행한다.
- 주변 재생에 위치 권한이 필요하거나 현재 위치를 확인하지 못하면 각각 안내한다. 정차 중 권한 요청 또는 다시 확인을 할 수 있다.
- 정차 화면에서 `자동 재생 종료`를 선택하면 현재 재생을 계속하면서 종료 예정 상태를 표시한다. `종료`는 즉시 정지하고 문장 체크포인트를 해제한다. 설정의 자동 재생 값은 각 이야기 완료 시점에 적용된다.
- 일시정지 후 또는 앱을 다시 연 뒤 `재생`을 누르면 마지막으로 완료한 문장 다음부터 이어듣는다. 중단된 문장은 처음부터 다시 들을 수 있다. 같은 계정 또는 비회원의 저장 위치가 있을 때 일시정지 상태에 문장 단위 이어듣기 안내를 표시한다.
- 일시적 Audio Focus 복귀는 사용자 일시정지·종료 이후의 자동 재개를 취소한다. 화면 꺼짐·Suspend 진입으로 중단한 경우 체크포인트를 유지하고 재생 자원을 해제하며, 화면 복귀 뒤 사용자의 재생 입력으로 이어듣는다.
- 파일 음원은 플레이어에서 확인한 재생 위치와 전체 길이를 표시한다. 정차 중 `오프라인 저장`을 선택하면 차량에 음원을 받는다. PLEOS TTS는 누적 청취와 서버 예상 길이를 표시한다.
- PLEOS 한국어 합성은 국가를 포함한 `ko-KR`로 요청한다. 시작 이벤트만으로 합성 성공을 판정하지 않고 완료·오류도 검증한다.

## SCR-NEXT-001 — 다음 Story
- 제목, Hook, Duration, 예상 거리
- Action: `재생`, `건너뛰기`

## SCR-DEST-001 — 목적지 Playlist
- 내비게이션에서 확인한 목적지와 남은 시간, 편성된 Story 수와 예상 재생 시간을 표시한다.
- `목적지 주변 이야기`는 목적지 주변 공개 Story를 뜻한다. 경로 좌표를 제공하는 환경에서는 서버의 경로 기준 편성을 `안내 경로 이야기`로 표시한다.
- Mode: `SHORT`, `STANDARD`, `FAMILY`
- Action: 개별 Story 듣기, `전체 재생`, `내비 상태 다시 확인`
- 목적지 또는 남은 시간이 없거나 도착까지 60초 미만이면 재생 편성 대신 해당 상태를 안내한다.

## SCR-COURSE-LIST-001 — ThemeCourse 목록
- 공개 코스 API의 제목, 설명, 예상 시간, 거리, 정차점·Story 수를 표시한다. 정차점이 하나면 정차점 사이의 주행 거리를 표시하지 않는다.
- 목록과 상세 탐색은 정차에서만 제공한다.

## SCR-COURSE-DETAIL-001 — ThemeCourse 상세
- 선택한 Course ID의 상세에서 장소와 공개 Story를 코스 순서대로 표시한다.
- Action: 개별 Story 듣기, `코스 이야기 듣기`, 코스 저장, `첫 장소 길 안내`
- 길 안내를 누르면 첫 장소의 이름을 보여 주고 확인을 받는다. 확인 시 정차 상태와 선택한 코스가 여전히 유효하면 첫 정차점만 내비게이션에 전달한다.

## SCR-DRIVE-LIMIT-001 — 주행 제한
- `REQ-PLAY-004`, `REQ-STORY-005`, `FLW-NAV-001`, `FLW-PLAY-001`, `AC-PLAY-002`와 연결한다.
- `주행 제한 중` 안내, 현재 Story 제목, 재생 상태를 표시한다. 시작 시 규제 상태 확인 전, 차량 서비스 연결 단절, 규제 소스 생성·조회·관측 실패에도 이 화면을 표시한다.
- 현재 Story의 `들은 시간`을 표시한다. 넓은 화면은 낭독이 남아 있을 때 `예상 남은 시간`도 표시한다.
- 재생·일시정지, 다음, 저장, 관심 없음, 종료만 제공한다. 버튼의 터치 영역은 80dp 이상이며 화면 폭에 맞춰 한 줄 또는 두 줄로 배치한다.
- 재생 준비 중에 재생·일시정지 버튼을 누르면 대기 중인 재생 요청을 취소한다. 종료는 대기 요청을 취소하고 재생 자원을 해제한다. 사용자가 다시 재생하면 선택한 Story를 재생한다.
- `관심 없음`을 선택하면 표시된 Story ID와 알 수 있는 주제를 차량에 저장하고 버튼에 선택 상태를 표시한다. 같은 Story에 대한 입력은 하나의 기록으로 유지한다.
- 메뉴, 설정, 화면 이동 버튼, 이전 Story, 재생 위치 이동, 전문, 이미지와 스크롤 영역을 숨긴다.
- 제한이 활성화되면 열린 메뉴를 닫는다. 제한 해제 신호가 들어오면 이전 화면을 다시 표시하며 메뉴는 닫힌 상태로 둔다.

## SCR-OFFLINE-001 — Offline
- 재생 화면에서 다운로드한 음원을 사용하면 `오프라인 · 저장된 음원`을 표시한다. 주행 제한 화면에서도 음원 상태를 표시한다.
- 저장한 음원이 없는 경우 정차 화면에 `내 이야기 보기`와 `다시 시도`를 표시한다. 내 이야기에서 저장한 Story를 선택하거나 최근 Story의 `재생`을 눌러 다운로드한 음원을 들을 수 있다.

## SCR-EMPTY-001 — Content 없음
- 문구: `이 지역의 이야기는 아직 준비 중입니다.`
- 공개 후보가 있었지만 설정과 관심 없음 때문에 모두 제외된 경우: `현재 설정에 맞는 이야기가 없어요.` 주차 중 `관심 주제 설정`, `다시 확인`을 제공한다.
