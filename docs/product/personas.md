# Persona

## PER-FAMILY-001 — 가족 운전자

- **Goal**: 이동시간을 가족 학습 경험으로 활용
- **Pain Point**: 긴 역사 설명, 아이의 지루함, 운전 중 조작
- **Need**: `FAMILY` 모드, 쉬운 어휘, 30~60초 Story, Auto-play
- **Requirement**: `REQ-PLAY-003`, `REQ-ROUTE-005`, `REQ-STORY-004`

## PER-WEEKEND-001 — 주말 탐험형 사용자

- **Goal**: 유명 관광지 밖의 지역 Story와 ThemeCourse 발견
- **Pain Point**: 분산된 정보, 관광지 중심 콘텐츠
- **Need**: 지역 밀도, Offline, 저장, Source
- **Requirement**: `REQ-COURSE-001`, `REQ-COURSE-006`, `REQ-STORY-001`

## PER-COMMUTE-001 — 출퇴근 운전자

- **Goal**: 익숙한 경로에서 새로운 Story 청취
- **Pain Point**: 반복 재생, 긴 Audio, Navigation 충돌
- **Need**: Duplicate Suppression, Personalization, Interrupt Recovery
- **Requirement**: `REQ-PLAY-005`, `REQ-PLAY-006`, `REQ-AREA-002`

## PER-HISTORY-001 — 지역 문화 애호가

- **Goal**: 깊은 맥락과 Source 확인
- **Pain Point**: AI 오류, 과도한 단순화, 논쟁의 사실화
- **Need**: Verification, Source, Fact·Legend 구분
- **Requirement**: `REQ-STORY-001`~`REQ-STORY-003`

## PER-TOURIST-001 — 여행자

- **Goal**: 검색 없이 이동 중 지역 이해
- **Need**: `DestinationPlaylist`, Offline, Localization
- **Requirement**: `REQ-ROUTE-002`, `REQ-OFF-002`, `REQ-NFR-007`

## PER-EDITOR-001 — Content Editor

- **Goal**: Source, Rights, Trigger, Review, Publish 관리
- **Need**: Map-based CMS, AI Draft, Version History
- **Requirement**: `REQ-CMS-001`~`REQ-CMS-007`

## PER-REVIEWER-001 — 검수자

- **Goal**: 사실, 연도, 이름, 발음, 불확실성 검증
- **Need**: Source·Script 비교, Comment, Audit History
- **Requirement**: `REQ-STORY-003`, `REQ-STORY-007`, `REQ-CMS-005`
