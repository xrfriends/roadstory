# 제품 개요(Product Brief)

## 제품명

**Road Story(로드 스토리)**

## Vision

검증된 지역 이야기를 실제 이동과 연결해 평범한 길을 새로운 발견의 경험으로 바꾼다.

## 문제

- 지역 정보가 여러 기관과 자료에 분산되어 있다.
- 운전 중 검색은 위험하다.
- 기존 관광 앱은 유명 관광지와 정해진 코스에 집중한다.
- 단순 위치 Trigger는 잘못된 도로·방향·시점에서 재생될 수 있다.
- AI 역사 콘텐츠는 근거 없는 정보를 포함할 수 있다.

## 해결책

- 위치·경로·방향·속도 기반 Story 선택
- 30초·60초 Audio First 콘텐츠
- 자유 주행, 목적지 Playlist, ThemeCourse
- Source와 검수일 표시
- Vehicle과 Mobile 역할 분리
- 기관용 Content CMS

## 주요 사용자

- 가족 운전자
- 주말 드라이브·국내여행 사용자
- 출퇴근 운전자
- 지역 문화 애호가
- 국내외 관광객

## MVP

### 포함

- Pilot 지역
- 검수 Story 300~500건
- ThemeCourse 10개
- 자동 재생, 목적지 Playlist, 저장, 이력, Offline
- 무료·유료 상품 실험

### 제외

- 전국 확장
- AI 자동 발행
- AR·Camera Recognition
- Social Feed
- 전체 다국어
- 모든 차량 Platform 동시 지원

## 장기 사업 방향

- 기관용 Content SaaS
- 지자체·문화기관 구축
- Vehicle·Navigation Content API
- White Label 관광 서비스
- Premium ThemeCourse Marketplace

## 경쟁우위

- 검증 Story Database
- Source·Review History
- 재생 시점·도로 방향 데이터
- Completion·Skip 데이터
- 지역 기관 Network
- Content CMS
- PLEOS 연동 경험
