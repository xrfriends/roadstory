| `TS-PLAY-012` | 재생 준비 중 일시정지 또는 종료 | 대기 요청을 취소하고 늦게 도착한 결과로 재생하지 않음. 종료 시 재생 자원 해제 |

| `TS-PLAY-014` | 완료 직전 Auto-play 켜기/끄기 또는 자동 재생 종료 예약 | 완료 시 현재 설정과 세션 예약을 확인. 예약은 현재 재생을 유지하고 이후 자동 전환만 막음 |
| `TS-PLAY-015` | 빈 후보, 조회 오류 또는 선택 ID가 후보에 없음 | 빈 상태와 오류를 구분. 개별 ID의 상세 재생을 우선하며 재시도 가능 |
| `TS-PLAY-016` | 가족 우선과 주제 빈도를 변경 | 적합 표시가 있는 가족 후보가 우선. 가족 우선이 꺼지면 주제 빈도와 서버 순서에 따라 선택. 불명확한 가족 분류는 가산하지 않음 |
| `TS-PLAY-017` | 청취 중 주제 끄기/켜기 또는 관심 없음 표시, 주변 재시작 | 현재 재생 유지. 이후 후보 재정렬·제외. 모두 제외되면 설정 안내. 사용자가 직접 선택한 Story는 재생 가능 |
| `TS-PLAY-018` | 정차 중 주변 재생에서 최근의 유효한 위치 수신 | 실제 위치의 반경 안에 있는 공개 Story만 반환한다. 속도와 진행 방향이 유효하면 후방 Story는 뒤로 보낸다. |
| `TS-PLAY-019` | 권한 거부, 낮은 정확도·신뢰도, 오래된 위치 또는 위치 확인 실패 | 주변 후보를 요청하지 않고 이유를 안내한다. 저장·이력에서 직접 선택한 이야기는 재생할 수 있다. |
| `TS-PLAY-020` | 문장 재생 중 사용자 일시정지 후 재생 | 완료한 문장은 유지하고 중단 문장을 다시 재생한다. 늦은 이전 문장 콜백은 체크포인트와 현재 재생에 영향을 주지 않는다. |
| `TS-PLAY-021` | 음성 시작 지연, 일시정지·Focus 대기, 중단 문장 재청취 | `들은 시간`은 실제 `PLAYING` 구간만 누적하며 중단 문장 재청취도 합산한다. 서버 예상 길이보다 짧을 때만 `예상 남은 시간`을 표시한다. |
| `TS-PLAY-022` | 일시적 Audio Focus 상실 후 복귀, 대기 중 사용자 종료·Story 전환 | 활성 체크포인트에서만 이어듣는다. 이전 Focus 이벤트와 콜백이 사용자 종료·새 Story를 되돌리지 않는다. |
| `TS-PLAY-023` | 재생 중 화면 꺼짐·Suspend 진입 후 복귀 | 문장 체크포인트를 유지하고 재생 자원을 해제한다. 복귀 뒤 사용자 재생 입력으로 이어듣는다. |
| `TS-PLAY-024` | 비회원과 계정 A의 문장 위치를 저장한 뒤 프로세스 재시작, 계정 B와 A로 전환 | 각 사용자의 일시정지 위치를 따로 표시한다. 같은 사용자가 `재생`을 누르면 저장 문장부터 이어지고, 계정 B에는 다른 사용자의 위치가 표시되지 않는다. |
| `TS-PLAY-025` | 저장 이후 낭독문 변경, 재생 중 네트워크 실패, 사용자 종료·자연 완료 | 변경된 낭독문은 첫 문장부터 시작한다. 다시 조회할 수 있을 때까지 저장 위치를 유지한다. 사용자 종료와 자연 완료는 현재 사용자의 위치를 지운다. |
| `TS-PLAY-026` | 파일 음원 재생·일시정지 후 앱 재시작 | 같은 파일의 플레이어 위치를 복원하고 사용자가 재생을 누르면 저장된 밀리초 위치로 이동한다. 다른 파일 버전은 처음부터 시작한다. |
| `TS-OFF-001` | 음원 다운로드 후 서버 단절, 앱 재시작과 재생 | 파일 무결성을 확인해 저장 음원을 재생하고 오프라인 상태를 표시한다. 파일이 손상됐거나 없으면 재시도 안내를 제공한다. |

## Route

| ID | Scenario | Expected Result |
|---|---|---|
| `TS-ROUTE-001` | 30분 Route | Audio Budget 내 Playlist |
| `TS-ROUTE-002` | 목적지 없음 | 자유 주행 안내 |
| `TS-ROUTE-003` | Re-route | 이후 Playlist 재구성 |
| `TS-ROUTE-004` | 3분 남음 | 짧은 Story만 포함 |
| `TS-ROUTE-005` | 내비 안내 중 목적지와 남은 시간이 있고 경로 좌표가 없음 | `DESTINATION_NEARBY` 기준으로 목적지 300m 이내 공개 Story를 편성한다. 남은 시간과 모드를 적용한다. 목적지나 남은 시간이 없거나 60초 미만이면 새 재생 편성을 시작하지 않는다. |
| `TS-ROUTE-006` | 유효한 Polyline5, 잘못된 경로, 재탐색, 안내 종료 | 유효 경로는 진행 순서를 사용한다. 잘못된 경로는 Problem Details로 응답한다. 재탐색은 현재 재생을 유지하고 이후 후보만 갱신하며 안내 종료 시 이후 후보를 비운다. |
