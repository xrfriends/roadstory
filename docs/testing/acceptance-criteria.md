# 인수 조건(Acceptance Criteria)

## AC-ONB-001
Given 최초 사용자  
When App 실행  
Then 가치, 위치 목적, 관심 주제가 3단계 이내 제공된다.

## AC-PLAY-001
Given 자유 주행 중이고 적합 Story가 있을 때  
When Eligibility Engine 실행  
Then 위치, 방향, cooldown, Preference를 만족하는 `PUBLISHED` Story만 반환한다.

## AC-PLAY-002

- Given 차량 앱의 주행 제한이 활성화되거나 규제 상태를 확인할 수 없는 상태
- When 화면을 표시하거나 조작 요청을 처리할 때
- Then `SCR-DRIVE-LIMIT-001`을 표시하고 재생·일시정지, 다음, 저장, 관심 없음, 종료만 제공한다. 메뉴·설정·이전 Story·재생 위치 이동·전문·이미지 탐색은 표시하지 않는다. 제한을 위반하는 이전 화면의 콜백과 시스템 미디어 명령은 실행하지 않는다. 제한 해제 신호가 들어오면 이전 화면으로 돌아간다.

## AC-PLAY-003
Given cooldown 이내 재청취  
Then 명시적 Replay가 아니면 자동 재생하지 않는다.

## AC-PLAY-004

- Given PLEOS TTS로 공개 Story를 문장 단위 재생 중일 때
- When Navigation·Call의 일시적 Audio Focus 상실과 복귀가 발생할 때
- Then 마지막 완료 문장 다음의 중단 문장부터 다시 재생한다. 사용자가 일시정지·종료했거나 다른 Story로 전환했다면 이전 Focus 복귀와 콜백으로 재개하지 않는다.
- Then `들은 시간`은 음성이 실제 시작된 `PLAYING` 구간만 누적한다. 준비·중단·Focus 대기 구간은 제외하며 중단 문장 재청취는 누적한다.
- Then 낭독이 남아 있고 서버 예상 길이보다 누적 청취 시간이 짧을 때 `예상 남은 시간`을 표시한다.
- When 화면 꺼짐·Suspend 진입으로 재생이 중단될 때
- Then 문장 체크포인트를 유지하고 재생 자원을 해제한다. 화면 복귀 뒤 사용자의 재생 입력으로 이어듣는다. `종료`는 현재 사용자의 체크포인트와 자동 재개 요청을 해제한다.
- When 앱 또는 재생 서비스가 다시 시작될 때
- Then 계정별·비회원별로 저장한 위치를 해당 사용자의 일시정지 상태에 표시한다. 사용자가 재생을 누르면 공개 Story 낭독문을 확인하고, 문장이 그대로라면 중단한 문장부터 이어듣는다.

## AC-PLAY-005

- Given 서로 다른 공개 Story가 순서대로 준비된 차량 재생 큐
- When 사용자가 다음을 누르거나 현재 Story가 끝날 때
- Then 수동 다음은 다음 ID를 즉시 재생한다. 자동 전환은 완료 시 설정이 켜져 있고 종료 예약이 없을 때만 실행한다. 마지막 항목에서 반복하지 않는다. `자동 재생 종료`는 현재 Story를 마치고, `종료`는 대기 중인 요청과 재개를 포함해 즉시 멈춘다.

## AC-PLAY-006

- Given 공개 주변 후보와 차량에 저장한 청취 설정이 있을 때
- When 주변 재생을 시작하거나 다음 후보를 결정할 때
- Then `끄기` 주제와 관심 없음 Story를 추천에서 제외한다. 가족 우선일 때 가족 적합이 명시된 Story를 먼저 고려하고, 그 안에서 관심 없음과 같은 주제를 뒤로 미룬 다음 `자주`, `가끔`, 서버 순서를 적용한다.
- Then 변경 중인 설정은 현재 Story를 중단하지 않고 다음 후보에 반영한다. 모두 제외되면 안내하고 자동으로 다른 Story를 재생하지 않는다. 저장·이력에서 사용자가 직접 선택한 ID는 재생할 수 있다.

## AC-PLAY-007

- Given 정차 상태에서 사용자가 주변 이야기 재생을 요청할 때
- When 위치 권한이 있고 위치 샘플이 30초 이내이며 제공자의 정확도 기준을 충족할 때
- Then 현재 위치에서 지정한 반경 안에 있는 공개 Story를 청취 설정과 함께 후보로 사용한다. 속도와 진행 방향이 유효할 때는 후방 Story의 우선순위를 낮춘다.
- Then 권한 거부, 오래된 위치, 낮은 신뢰도 또는 조회 실패에서는 주변 재생을 시작하지 않고 상태를 안내한다. 사용자가 직접 고른 Story는 위치 없이 재생할 수 있다.

## AC-ROUTE-001
Given 목적지와 Route  
When 목적지 Story 요청  
Then 남은 시간에 맞는 정렬된 `DestinationPlaylist`를 생성한다.

## AC-ROUTE-002
Given Playlist가 있고 Re-route 발생  
Then 현재 Story는 유지하고 이후 Story만 다시 계산한다.

## AC-ROUTE-003

- Given 내비게이션 안내 중 목적지와 남은 시간을 확인할 수 있을 때
- When 사용자가 목적지 편성을 요청할 때
- Then 경로 좌표가 없으면 목적지 300m 이내 공개 Story를 편성하고 화면에 목적지 주변 기준을 표시한다. 경로 좌표가 있으면 경로 진행 순서로 후보를 편성한다.
- Then 도착까지 60초 미만이거나 목적지·남은 시간이 확인되지 않으면 새 편성을 시작하지 않는다. 편성에는 선택한 모드와 도착 전 30초 여유를 적용한다.

## AC-COURSE-001
Given Published ThemeCourse  
When 시작  
Then 확인 후 첫 Stop Navigation을 시작한다.

## AC-COURSE-002

- Given 공개 코스의 목록 또는 상세가 열렸을 때
- When 해당 코스 또는 코스 안의 Story를 선택할 때
- Then 선택한 Course ID와 실제 공개 Story ID를 사용하며, 코스 정차점·Story 순서를 재생에 반영한다. 첫 장소 길 안내는 사용자가 정차 상태에서 별도로 확인한 경우에만 요청한다.

## AC-STORY-001
Given Publish 시도  
When Source 없음  
Then Publish를 차단한다.

## AC-STORY-002
Given 논쟁·전설 포함  
Then 해석 또는 전설 Label을 표시한다.

## AC-OFF-001

- Given 발행된 Story의 음원을 차량에 다운로드했고 서버에 연결할 수 없을 때
- When 사용자가 해당 Story 재생을 요청할 때
- Then 검증된 저장 음원을 재생하고 오프라인 상태를 표시한다. 같은 파일의 일시정지 위치가 있으면 해당 위치에서 이어듣는다.
- Then 저장 음원이 없거나 손상된 경우 현재 상태와 재시도 동작을 제공한다.

## AC-USER-001

- 비회원은 공개 이야기와 코스를 조회·재생하고 차량 로컬에 저장한다. 계정 보관함 API는 인증을 요구한다.
- 인증 계정에서 저장·해제와 청취 이력은 즉시 표시되고 서버를 통해 같은 계정의 다른 기기에 반영된다. 한 계정의 데이터나 대기 요청은 다른 계정에 반영되지 않는다.
- 동일 쓰기 요청을 재시도해도 중복되지 않는다. 같은 Story의 오래된 청취 요청이 최근 기록을 덮어쓰지 않는다.
- 비회원 저장은 정차 중 직접 선택할 때 계정에 복사한다. 로그인 자체는 비회원 기록을 업로드하지 않는다.
- 재생 중 인증이 만료되면 이미 시작한 공개 이야기만 이어서 듣고 이전 계정의 대기열은 비운다.
