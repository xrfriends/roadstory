# 성수동 수제화 거리 시연 음원

`story-published-1.m4a`는 Road Story에서 발행한 「성수동 수제화 거리」의 본문 전체를 [Supertone Supertonic 3](https://huggingface.co/Supertone/supertonic-3)의 F1 음성으로 합성한 AI 낭독입니다. 발행 본문을 그대로 사용했습니다. 재생 서버는 함께 둔 JSON에서 재생 시간과 본문 해시를 읽습니다.

Supertonic 3 모델의 [OpenRAIL-M 라이선스](https://huggingface.co/Supertone/supertonic-3/blob/main/LICENSE)가 음성 생성에 적용됩니다.
